Happy Mixer DJ - USB Release

Expected folder structure:

Happy-Mixer-DJ-USB/
├── macOS/
│   └── Happy Mixer DJ.dmg
├── Windows/
│   └── Happy Mixer DJ.exe or Happy Mixer DJ.msi
├── START-HERE.txt
└── README.txt

Build the macOS installer on a Mac and the Windows installer on Windows. Use an exFAT-formatted USB drive when sharing files between both operating systems. The app runs locally and loads music files from the computer; music files are not included in the installer.
