Happy Mixer DJ - Offline Desktop DJ Software

Project: m87y92vvjd-dotcom/happy-mixer-dj
Repository: https://github.com/m87y92vvjd-dotcom/happy-mixer-dj

Happy Mixer DJ is an offline desktop DJ application for macOS and Windows. It supports four local audio decks, playback controls, cue points, pitch, volume, master output, and crossfader mixing.

To build on macOS:
1. Install Xcode Command Line Tools: xcode-select --install
2. Install Node.js 20 or newer and Rust.
3. Open Terminal and enter:
   cd happy-mixer-dj
   npm ci
   npm run typecheck
   npm run tauri:build
   npm run usb:prepare
4. Find the macOS installer in src-tauri/target/release/bundle/dmg/.

To build on Windows:
1. Install Node.js 20 or newer and Rust.
2. Install Visual Studio Build Tools with Desktop development with C++, MSVC, and the Windows SDK.
3. Open PowerShell and enter:
   cd happy-mixer-dj
   npm ci
   npm run typecheck
   npm run tauri:build
   npm run usb:prepare
4. Find the Windows installer in src-tauri/target/release/bundle/nsis/ or msi/.

USB layout:
Happy-Mixer-DJ-USB/
  macOS/Happy Mixer DJ.dmg
  Windows/Happy Mixer DJ.exe
  START-HERE.txt
  README.txt

Build macOS installers on macOS and Windows installers on Windows. Format a shared USB drive as exFAT. The installed app runs offline and loads local music files. Unsigned installers may show an operating-system security warning.
